# What happens when data breaks?

## Problem
Real-world data is often incomplete or noisy.
I wanted to see how this affects a machine learning model.

## What I did
- loaded a dataset
- trained a simple model
- introduced noise into the data

## What I observed
- model accuracy dropped
- some features had more impact than others

## Why it happened
Machine learning models rely heavily on clean and consistent data.
When data quality drops, predictions become less reliable.

## Conclusion
Understanding how models fail is important.
A system is only as good as the data it receives.
